# 购买 VPS 指南（写给第一次买的人）

> 目标：花最少的钱和最少的时间，拿到一台「能稳定连上、IP 没被封」的境外服务器，
> 然后把 [服务端搭起来](VPS-服务端搭建.md)，回来加速推特。
>
> 本文不含任何返利/推广链接，也不替任何商家背书 —— 只讲怎么判断和怎么下单。

---

## 一、先明确你要买什么

搭代理只需要极低的配置：

| 项目 | 最低要求 | 推荐 | 说明 |
| --- | --- | --- | --- |
| CPU | 1 核 | 1 核 | 代理几乎不吃 CPU |
| 内存 | 512 MB | 1 GB | 512MB 够跑 sing-box；1GB 更从容 |
| 硬盘 | 10 GB | 20 GB | 系统占 2～3 GB，其余基本用不上 |
| 流量 | 500 GB/月 | 1 TB/月 | **这是最该关注的指标**，见第四节 |
| 带宽 | 100 Mbps | 500 Mbps～1 Gbps | 决定高峰期的速度上限 |
| 系统 | Debian 12 / Ubuntu 22.04+ | 同左 | 跟着指南走就选这个 |
| 位置 | 日本 / 新加坡 / 韩国 / 美国西海岸 | 日本 或 新加坡 | 见第二节 |

**别买的东西**：独立服务器、GPU、高防 IP、Windows 授权、托管面板（cPanel/Plesk）——
搭代理一个都用不上，纯属浪费钱。

## 二、机房位置怎么选

你在中国大陆访问，位置直接决定延迟（延迟越低，推特刷起来越跟手）：

| 位置 | 典型延迟 | 适合度 | 备注 |
| --- | --- | --- | --- |
| 日本（东京/大阪） | 30～70 ms | ⭐ 首选 | 综合最好，X 风控也相对宽松 |
| 韩国（首尔） | 40～80 ms | ⭐ 很好 | 与日本接近，商家略少 |
| 新加坡 | 60～100 ms | 好 | 备选，国际出口好 |
| 美国西海岸（洛杉矶/圣何塞） | 130～180 ms | 可用 | 便宜、商家最多；延迟偏高但完全能用 |
| 香港 | 10～40 ms | ⚠️ 慎选 | 延迟最低，但**很多香港 IP 段已被 X 标记**，容易触发验证甚至封号 |
| 欧洲 | 200 ms+ | ❌ | 除非有特殊需求 |

**结论**：优先日本；预算紧张就美国西海岸（便宜很多，日常刷推特感觉差别不大）。

## 三、怎么选商家（按你的情况对号入座）

### 情况 A：第一次买，怕踩坑、想随时退

选**按小时计费**的大厂，这类商家价格透明、支持信用卡/PayPal、可随时销毁退款：

- **Vultr**：东京/新加坡/洛杉矶等多机房，最低约 $3.5～6/月，按小时计费
- **DigitalOcean**：最低约 $4～6/月，界面最友好，适合完全新手
- **Linode（Akamai）**：稳定，$5/月起

优点：随时开随时删（删了就不再计费），可以先开一台测试，不满意换机房重开。
缺点：单价贵一些；**这几个商家的 IP 段被用得多，容易碰到已经被墙的 IP**。

### 情况 B：预算优先、能接受年付

选**低价年付**商家，常见约 $10～30/年（1 核 1GB 级别）：

- **RackNerd**：常年有年付促销，美国机房居多，价格最低档
- **搬瓦工（BandwagonHost）**：老牌，有 CN2 线路（对国内优化，贵一些但更稳），支持支付宝
- **CloudCone / GreenCloud** 等：同类低价年付

优点：便宜，很多支持支付宝。
缺点：**年付意味着 IP 被封也基本没法退款**；超售严重时高峰期速度会掉。

### 情况 C：不想折腾，直接买"机场"订阅

如果你只是要能上推特、不想管服务器：直接买现成的订阅服务（机场），
把订阅链接填进本软件的「订阅」页即可，不用买 VPS、不用看本文档。
代价是：线路质量与隐私取决于商家，且需要甄别商家是否可靠。

## 四、四个必须避开的坑

### 坑 1：只看价格，不看流量

流量单位是**每月重置的总额**，1 TB = 1024 GB。参考消耗：

| 用途 | 每小时消耗 | 每月（每天 3 小时） |
| --- | --- | --- |
| 刷推特、看图文 | 约 50～150 MB | 约 5～14 GB |
| 看 YouTube 1080p | 约 1.5～3 GB | 约 135～270 GB |
| 看 YouTube 4K | 约 7 GB | 约 630 GB |

**只看推特，500 GB/月绰绰有余**；如果你还打算用它看视频，务必买 1 TB 以上或选不限流量的商家。

### 坑 2：买完发现 IP 已经被封

低价商家（尤其是年付促销）常把**被墙的 IP 段**反复回收再卖。规避方法：

1. **优先按小时计费的商家**：开一台 → 用 `ping` 或本文档后面的方法测通不通 → 不通就删掉重开
   （这招只在按小时计费的商家有效，年付商家删了钱不退）
2. 下单前看商家是否明确提供**"换 IP"服务**（有的免费、有的收 $2～3 一次）
3. 别买那种"超低价 + 大量机房任选"的套餐，这类 IP 池通常被用烂了

### 坑 3：被"续费涨价"和"首月特价"套路

留意**续费价格**而不是首购价格。有些商家首月 $1，续费 $12。下单页面一定要看
"Renewal price" 那一栏。

### 坑 4：付款方式与实名问题

- 国外商家主流是**信用卡 / PayPal**；部分（搬瓦工、RackNerd 等）**支持支付宝**，对国内最方便
- 部分商家需要邮箱验证，建议用一个能正常收信的邮箱
- 虚拟信用卡（如各种 U 卡）成功率不稳定，不作为首选

## 五、下单流程（通用步骤）

以按小时计费的商家为例，各家的按钮名称大同小异：

1. **注册账号**：邮箱 + 密码，完成邮箱验证
2. **充值 / 绑定支付方式**：信用卡或 PayPal；支持支付宝的商家会显示 Alipay 图标
3. **Deploy / Create 新服务器**，依次选择：
   - **Location（机房）**：按第二节选，优先 Tokyo
   - **Image / OS**：**Debian 12 x64**（或 Ubuntu 22.04 x64）—— 别选带面板的镜像
   - **Plan（套餐）**：最低档即可（1 核 / 512MB～1GB / 10～20GB）
   - **额外选项全部关掉**：自动备份（Auto Backup）、IPv6（可留可关）、监控、DDoS 高防
   - 有的商家会让你选 **SSH Key**（推荐）或 **Password**（更简单，先选密码）
4. **确认下单**，等 30 秒～2 分钟，状态变成 **Running** 就绪
5. **记下三样东西**（这是你后面唯一的入口，务必存好）：
   - **IP 地址**
   - **root 密码**（或 SSH 私钥文件）
   - 商家控制台地址

## 六、买完立刻做两件事（别跳过）

### 1. 测端口通不通

在你自己电脑上（Windows PowerShell）：

```powershell
Test-NetConnection 你的服务器IP -Port 22      # SSH 端口，必须 True，否则你连不上服务器
Test-NetConnection 你的服务器IP -Port 443     # 搭好服务端后要用的端口
```

`TcpTestSucceeded : True` 才算通。**如果是 False**：先检查商家后台的**防火墙 / 安全组**
是否放行了该端口（这是新手最常卡住的地方），其次才怀疑 IP 被墙。

### 2. 登录并搭服务端

```powershell
ssh root@你的服务器IP
```

第一次连接会问 `Are you sure you want to continue connecting?`，输入 `yes`，
然后粘贴密码（**输入密码时屏幕不会显示任何字符，这是正常的**，直接粘贴后回车）。

登录成功后，按 [VPS-服务端搭建.md](VPS-服务端搭建.md) 第 1 节往下做即可。

## 七、常见问题

| 问题 | 回答 |
| --- | --- |
| 需要备案吗？ | 不需要。境外服务器不涉及国内备案 |
| 可以用国内云厂商（阿里云/腾讯云）吗？ | 可以买，但要选**境外地域**（如香港、新加坡、东京）；国内地域的机器无法用于此用途 |
| 一定要域名吗？ | **不需要**。本文档推荐的 VLESS+Reality 方案不需要域名也不需要证书 |
| 1 核 512MB 会不会不够？ | 跑代理足够。只有你打算同时跑别的服务才需要升配 |
| 可以几个人合用吗？ | 技术上可以（服务端加多个 UUID），但请遵守当地法律法规，并自行评估风险 |
| 买完发现太慢怎么办？ | 按小时计费的商家直接删掉换机房重开；年付商家只能等下次续费时换 |
| 服务器会被封吗 / 会被停机吗？ | 有可能遇到 IP 被墙（换 IP 即可）或商家因投诉停机。所以别把重要资料只存在这台机器上 |

## 八、给你的最短路径建议

**如果你想今天就用上推特**：

1. 选一个**按小时计费**的商家（Vultr / DigitalOcean 之类），开一台**东京**、**Debian 12**、最低配
2. 用第六节的两个 `Test-NetConnection` 确认 22 和 443 通
3. 按 [VPS-服务端搭建.md](VPS-服务端搭建.md) 搭 VLESS+Reality，拿到分享链接
4. 粘进本软件「节点」页 → 导入 → 回「加速」页启动 → 点「检测 X 可达性」确认
5. 如果这台 IP 不通，**删掉重开一台**（按小时计费只损失几毛钱）

**如果你想省钱且有耐心**：选低价年付商家（RackNerd 之类，支持支付宝），
但要有"IP 不通就换"的心理准备，并且优先挑提供免费换 IP 的商家。

## 九、安全提醒

- 购买与使用请遵守你所在国家或地区的法律法规
- 妥善保管服务器 IP、密码、订阅链接，泄露等于把你的线路送人
- 服务器只用来做代理，不要在上面放任何重要数据
- 定期 `apt update && apt upgrade` 保持系统更新
